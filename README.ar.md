# SAJJAD Design DNA — النسخة العربية

**طوّرها سجاد أحمد غنيم**، مع الاحتفاظ بحقوق المؤلفين الأصليين للأجزاء المستخدمة من مشروع [zanwei/design-dna](https://github.com/zanwei/design-dna) المرخص MIT.

المهارة تساعدك تفهم البصمة البصرية لأي تصميم: الألوان، الخطوط، المسافات، الأسلوب العام، والمؤثرات. بعدها تراجع جودة القواعد، وتصدّرها، وتستخدمها لبناء تصميم جديد أصلي.

## شنو الجديد؟

- فحص تباين النص والخلفية مع نسب WCAG 2.2 AA.
- تنبيهات مرتبطة باللغة العربية والاتجاه من اليمين لليسار (RTL).
- إخراج متغيرات CSS وملف Design Tokens بصيغة DTCG 2025.10.
- مقارنة ملفين DNA لمعرفة أي الألوان أو الخطوط أو المسافات تغيّرت.
- إنشاء تقرير HTML مرتب يعرض الهوية والتنبيهات.
- تمييز المعلومات المقاسة من الصور عن القيم المخمنة، لأن بعض التفاصيل مستحيل نتأكد منها من Screenshot وحدها.

## التثبيت على Codex

~~~powershell
npx skills add Sajjad-Ahmed1/Design-DNA-Skill -a codex -g
npx skills list -g
~~~

راجع ملفات المستودع قبل تثبيت المهارات الخارجية. تحتاج Node.js؛ وأوامر قياس الألوان بالصور تحتاج أيضاً تثبيت مكتبة Sharp:

~~~bash
npm install --prefix scripts
~~~

## مثال على تجربة قابلة للنشر

1. خذ صورة Screenshot لموقع يعجبك، من دون نسخ شعاره أو محتواه.
2. أرفق الصورة في Codex، واطلب استخدام مهارة SAJJAD Design DNA.
3. يخزن الوكيل ملف DNA موضحاً الألوان والقواعد والأشياء التي تم قياسها والأشياء التقديرية.
4. نفّذ أمر التدقيق: node scripts/audit.mjs examples/sample-dna.json
5. صدّر CSS Tokens، وابنِ تصميم مختلف تماماً بنفس الروح البصرية.
6. اعرض المرجع والتصميم الجديد ونتيجة تقرير الجودة في الريلز.

## نقطة مهمة

هذه **مهارة لبرمجيات الوكلاء AI** وليست حالياً إضافة Figma مستقلة أو موقعاً يستخرج كل التفاصيل بزر واحد. لا تدّعي الحصول على خط أو قياس دقيق من صورة فقط من دون دليل. نتائج فحص التباين لا تعني اجتياز كل معايير الوصول.

الاسم والميزات الجديدة تُنسب إلى سجاد كمطوّر؛ الكود الأصلي ومصادره تبقى منسوبة لأصحابها. التفاصيل في NOTICE.md.
